# GLAB 934.2.3: Cyber Incident Response with Generative AI

Welcome to the Cyber Incident Response lab! 

In this exercise, you will use Generative AI (specifically the GPT-2 language model) to simulate a cyber incident. You will then structure that data, use Machine Learning to detect anomalies, and ask the AI to generate an incident response.

## 🚀 Getting Started

The environment comes pre-configured with all the necessary Python libraries (like `transformers`, `torch`, and `scikit-learn`). You **do not** need to run any `pip install` commands. 

### How to begin:
1. Look at the **Explorer** panel on the left side of your screen.
2. Open the `notebooks` folder.
3. Click on the file named **`GLAB-934.2.3.ipynb`** to launch the Jupyter Notebook.

## 📓 Working in the Notebook

Once your notebook is open:
1. In the top right corner, click **Select Kernel** and choose **Python Environments** -> **Python 3.12.x** (or whichever version is recommended).
2. Run the cells in order from top to bottom. You can run a cell by clicking the **Play (▶)** button next to it, or by pressing `Shift + Enter`.
3. Wait for the AI model to finish downloading in Cell 1 (you will see a progress bar). 

## 📝 Assignment

At the bottom of the notebook, you will find the **Reflection Questions**. Read through the outputs generated by the AI and the K-Means clustering, then type your answers directly into the notebook or your lab document.

*(Note: The GPT-2 model used in this lab is a base-level AI. It may generate repetitive or unexpected text—this is normal! It is part of the exercise to observe how AI behaves and where human oversight is still required.)*
